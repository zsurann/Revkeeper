# Sicurezza

Hai trovato un problema di sicurezza in Revkeeper? Scrivi a **revkeeper.app@gmail.com**, non aprire una issue pubblica.

- Descrivi il problema e come riprodurlo; rispondiamo entro 7 giorni.
- Prova solo sul tuo account: niente accessi ai dati di altri, niente test di carico contro `revkeeper.pages.dev`.
- Dopo la correzione, se vuoi, ti citiamo qui.
